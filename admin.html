Paste your editor key to start. You only need to do this once on each device.

How do I get an editor key?
  1. Sign in to github.com and go to Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Click Generate new token. Name: Website editor. Expiration: the longest available.
  3. Repository access: Only select repositories → Vilasini.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Click Generate token, copy it and paste it above.
